# Naomi | My Life, My Space

A personal life dashboard built with React, Vite, and Tailwind CSS.

## Setup

1. Open this folder in VS Code.
2. Open a terminal in the folder and run:

   npm install

3. Start the dev server:

   npm run dev

4. Open the local URL shown in the terminal (usually http://localhost:5173).

## Notes

- All data (tasks, mood, journal, goals, sleep) saves automatically in the browser using localStorage, so it stays there when you close and reopen the app.
- The Home page is fully built out. Other sidebar sections (Calendar, Education, Career/NSS, Love Life, Finance, Memories, etc) have placeholder pages ready to be built next, section by section.
- To deploy, run `npm run build` and upload the generated `dist` folder to Vercel like your other projects.
